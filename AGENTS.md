# AGENTS.md

## Project purpose

This repository is an unofficial TypeScript MCP stdio server for PriceProfeet API 1.0.0. The public compatibility surface is the ordered set of 24 MCP tools in `src/tools/definitions.ts`, their names, descriptions, and input schemas.

## Runtime path

1. `src/index.ts` loads `.env` and calls `serveStdio(() => createMcpServer())`.
2. `src/server.ts` creates a fresh official `McpServer`, registers the complete deterministic tool catalog, and maps API responses to MCP content.
3. `src/tools/definitions.ts` owns endpoint paths, methods, query/body mapping, tool metadata, and Zod input validation.
4. `src/api/client.ts` owns URL construction, `X-API-Key`, `User-Agent`, JSON encoding, timeout behavior, and upstream error translation.
5. `src/config.ts` is the only environment-reading boundary.

`dist/` is generated by `npm run build`. Never edit it directly.

## Commands

```bash
npm install
npm run format
npm run lint
npm run typecheck
npm test
npm run build
npm run check
npm run inspect
```

`npm test` is safe and does not call the live API. `npm run inspect` starts an interactive process; tool calls made in Inspector are live upstream calls and consume rate limits. No automated test may require a real PriceProfeet key.

## Change recipes

### Add or modify an API endpoint

1. Confirm the current contract in `https://www.prijsprofeet.nl/openapi.json` or `/docs`; do not infer undocumented fields.
2. Add/update exactly one definition in `src/tools/definitions.ts`.
3. Preserve deterministic tool order and update the exact-name parity assertion in `tests/server.test.ts`.
4. Add request mapping and boundary validation tests. Use dependency injection or a stubbed global fetch; never add a live network dependency.
5. Update the tool table and API caveats in `README.md`.
6. Run `npm run check`, then smoke-test the built stdio process through the official client test.

### Change HTTP behavior

Test outbound URL, repeated query keys, headers, body, timeout/error handling, and secret non-disclosure in `tests/api-client.test.ts` first. Keep all HTTP behavior in `src/api/client.ts`; tool handlers must not call `fetch` directly.

## Invariants

- Use official split MCP v2 packages: runtime server code imports `@modelcontextprotocol/server`; integration tests import `@modelcontextprotocol/client`.
- Keep `createMcpServer` transport-independent and injectable. Keep stdio setup in `src/index.ts` only.
- Stdout belongs exclusively to MCP protocol traffic. Diagnostics go to stderr.
- Every OpenAPI operation gets one tool; reject duplicate or missing public names through exact parity tests.
- Validate all arguments with Zod before an upstream call. Encode path values with `encodeURIComponent`.
- Never log API keys, full upstream error payloads, or user email request bodies.
- Never bypass PriceProfeet anti-bot controls, authentication, rate limits, or terms. Do not add automatic retries for `429`.
- Keep the configured User-Agent recognizable and free of `bot`, `crawler`, `spider`, and `slurp` for keyless use.
- Matching output is not automatically a current price. Preserve and document `is_current_deal`, `promotion_status`, `valid_from`, and `valid_until`; never compute an unqualified cheapest price from all matches.
- `.env` is local-only. Add new variables to `.env.example`, `src/config.ts`, and the README configuration table together.

## Testing expectations

Follow test-driven development: write and run a failing behavior test before production code. The minimum relevant layers are:

- API adapter behavior: `tests/api-client.test.ts`;
- exact registry, schema validation, and in-memory protocol behavior: `tests/server.test.ts`;
- packaged stdio handshake: `tests/stdio.test.ts`.

Before finishing, run `npm run check` and inspect `npm pack --dry-run`. If a live API smoke test is explicitly requested, use a bounded public endpoint, identify the client via User-Agent, make no retries, and state whether a key was used without exposing it.
